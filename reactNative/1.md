# PostgreSQL 使用

###PostgreSql Docker compose运行配置 docker-compose.yml

> 先创建网络（命令行）
> docker network create shared-network

```

networks:
  shared-network:
    external: true  # 使用已存在的网络
    name: shared-network

services:
  postgres:
    image: postgres:17
    container_name: postgres_db
    restart: unless-stopped
  
    environment:
      # 注意：这里设置的密码要与原系统一致，或者后续修改
      POSTGRES_PASSWORD: xinde1991 
      POSTGRES_USER: postgres  # 使用默认超级用户
      PGDATA: /var/lib/postgresql/data/pgdata
  
    ports:
      - "5432:5432"
  
    volumes:
    # 使用命名卷(postgres_data挂载到容器内/var/lib/postgresql/data)
      - postgres_data:/var/lib/postgresql/data 
      # 挂载备份文件目录，方便恢复
      - /tmp:/tmp/backups
  
    networks:
      - shared-network

volumes:
# 声明一个名为 postgres_data 的命名卷。docker Volume --help查看相应用法
# Docker 管理的 Volume，实际存储在/var/lib/docker/volumes/postgres_data/_data/
  postgres_data: 
    driver: local
    name: postgres_data
```

### PostgreSQL 导出和恢复指定数据库

```Shell
#导出数据库
pg_dump -U postgres -h localhost databaseName > databaseName.sql
#恢复数据库
#恢复前需准备好目标数据库。为避免冲突，推荐从干净的 template0 数据库创建
pg_dump -U postgres -h localhost  #进入数据库
CREATE DATABASE databaseName TEMPLATE template0;
exit;
psql -U postgres -h localhost -d databaseName -f databaseName.sql; #恢复数据库
```
